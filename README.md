# 信息图形研究与案例库

本仓库建立可持续迭代的信息图形研究体系，分为两部分：

1. **五大信息图形类型研究**：编年型、层级型、编目型、字母表型、地理图形型。每类设置概念总文档和独立案例分析报告；总文档随案例积累持续修订。
2. **常用信息图形案例库**：以具体图形类型为单位建立子目录，记录示例图、数据结构、统计图形及应用、视觉编码、信息框架和叙事框架。

## 目录导航
- 01-编年型信息图形 Chronological Infographics
- 02-层级型信息图形 Hierarchical Infographics
- 03-编目型信息图形 Cataloged Infographics
- 04-字母表型信息图形 Alphabet Infographics
- 05-地理图形信息图形 Geographical Infographics
- 常用信息图形案例库

## 统一研究维度
五大类型概念文档统一回答：A.基本数据逻辑；B.统计图形与计算方式；C.视觉编码；D.数据/信息架构；E.视觉叙事架构；并补充适用场景、局限和案例修订记录。

## 案例研究原则
- 先记录来源、原始图像和可核验信息，再进行分析；不将推测写成事实。
- 区分图形的**数据组织逻辑**与**视觉表现形式**。相同图表形式可能服务于不同信息类型。
- 每份案例报告完成后，回看所属类型的概念总文档，提炼共性、补充边界条件并记录修订。
- 暂无原始示例图的目录只保留说明文件，不虚构案例图片或来源。
- 新增分类时沿用既有结构，不随意改变五大类型的命名和编号。

## 案例报告流程
来源登记 → 图像/内容拆解 → 数据逻辑判断 → 统计图形识别 → 视觉编码分析 → 信息架构分析 → 叙事路径分析 → 适用性评价 → 更新概念总文档。
