# HOW-TO 信息图：叙事框架

## 1. 叙事目标
HOW-TO 的叙事不是讲述事件，而是引导读者从当前状态抵达目标状态。每一项信息都应帮助读者理解下一步行动、判断条件或完成标准。

## 2. 标准路径
任务目标 → 前置条件 → 准备工具/材料 → 按步骤执行 → 条件判断/异常处理 → 完成检查 → 最终结果。

## 3. 叙事节奏
- 开头：说明为什么做、做完是什么结果；
- 中段：按最小可执行动作拆分步骤；
- 转折：明确选择、失败、循环或风险；
- 结尾：给出验证标准和后续维护建议。

## 4. 可读性原则
一次只要求读者完成一个主要动作；将复杂动作拆分；提前提示高风险步骤；把必要条件放在执行之前；不要隐藏分支或把失败路径省略。

## 5. 评价标准
读者能否快速找到起点？是否知道每一步做什么？是否知道何时进入分支？是否能判断成功？遇到失败是否知道如何处理？
