# 第五章：表达与挖掘——补充案例分析

## 1. 课件内容范围
本组包括第62页章节过渡页，以及第64—72页的内容与风格、深度挖掘、美化信息图、可视化轮盘、结构优先和形式新奇性等示例。

## 2. 核心观点
- 信息图是表达观点和挖掘信息的工具。
- 设计前应充分利用空间进行合理、有限的深度挖掘。
- 信息图不应简化信息本身，而应让信息更清晰，即简化形式而不是删减必要内容。
- 应先组织数据结构，再考虑修饰和风格。
- 设计者不能预设读者理解力低而主动删去复杂信息。
- 美化的价值在于增强理解，而不是单纯增加视觉效果。
- 应谨慎使用新奇形式；形式越不寻常，越需要检查是否引入冗余。

## 4. 研究结论
有效的信息图不是删掉复杂内容，而是建立可理解的层级和导航，让读者从概要进入细节。形式服务于内容，修饰必须有助于理解。
