## 每类目录结构
- `类型分析.md`：定义该类型的主导数据逻辑、图形模型、视觉编码、信息架构、叙事方式和局限。
- `01-示例图/`：保存原始案例图片和来源说明。
- `案例分析报告/`：每个PPT案例单独建立分析报告。

## 案例研究规范
1. 先记录PPT页码、原始图像和可核验来源。
2. 分清“PPT原章节归属”与“依据图像结构得出的类型判断”，遇到不一致时明确标记，不静默改类。
3. 识别数据逻辑、统计图形、视觉编码、信息架构和视觉叙事。
4. 不根据装饰性图形推断数值；没有图例或数据口径时标记待核验。
5. 原始作者、链接、日期、数据源和版权信息未在课件中提供的，不作猜测。
