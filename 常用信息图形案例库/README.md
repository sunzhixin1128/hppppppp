# 常用信息图形案例库

本目录按具体的信息图形表现类型建立子目录。当前先建立三类基础分类：
- 词云图
- HOW-TO 信息图
- 文字型信息图

每个类型子目录统一包含：
1. 01-示例图：保存原始示例图、必要的局部截图和来源说明；
2. 02-分析报告.md：对案例整体进行综合分析；
3. 03-数据结构.md：说明原始数据、字段、关系和预处理；
4. 04-统计图形及应用.md：说明统计方法、图形模型和适用场景；
5. 05-视觉编码.md：分析位置、尺寸、形状、色彩、文字、线面等编码；
6. 06-信息框架.md：拆解信息模块、层级和阅读组织；
7. 07-叙事框架.md：分析叙事目标、阅读路径和信息节奏。

当前尚未提供具体案例图片，因此先建立研究文档框架，不虚构示例图或案例来源。后续收到真实案例后，再补图、逐案分析并完善文档。
