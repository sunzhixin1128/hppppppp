# 文字型信息图：信息框架

## 1. 推荐模块
1. 主标题：表达主题或核心结论；
2. 导语：交代背景、问题和阅读价值；
3. 主体分区：按论点、主题或问题分组；
4. 关键数字/事实：突出核心证据；
5. 引文/案例：提供原始材料或具体例证；
6. 注释：解释术语、口径和限定条件；
7. 总结：回收核心观点或给出行动建议；
8. 来源：标注引用、数据和图片来源。

## 2. 组织方式
- 论证型：观点 → 证据 → 分析 → 结论；
- 说明型：概念 → 特征 → 分类 → 应用；
- 清单型：总览 → 条目 → 条目说明；
- 对比型：比较对象 → 共同维度 → 差异 → 结论；
- 引文型：核心引文 → 背景 → 解释 → 出处。

## 3. 审核清单
标题是否承诺了正文无法支持的结论？每个模块是否有明确功能？重点信息是否有证据？读者能否通过标题和小标题快速扫描全文？
