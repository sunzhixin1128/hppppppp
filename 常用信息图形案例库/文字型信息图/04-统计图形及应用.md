# 文字型信息图：统计图形及应用

## 1. 文字本身的结构化统计
可用于辅助编辑和版式决策的指标包括：总字数、段落数、句子数、标题与正文的字数比例、列表条目数、引文数量、关键词出现频次、数字/日期/专有名词数量、模块平均长度与阅读时间估算。

这些指标主要用于内容管理，不应自动等同于信息重要性。

## 2. 可搭配的统计图形
- 条形图/点图：表达关键数值或分类比较；
- 数字卡片：突出少量核心指标；
- 时间轴：当文本包含明确时间序列时；
- 流程图：当文本描述操作步骤时；
- 引文卡片和注释图：突出观点、证据和解释。

## 3. 应用原则
如果核心信息是文字论述，不应为了“信息图”而强行添加无关统计图。图表应解决文字难以高效表达的比较、趋势、比例或流程问题。

## 4. 需要核验
数字是否有单位和口径；图表是否与正文一致；引用是否准确；文本删减是否改变限定条件；统计指标是否被误读为结论。
