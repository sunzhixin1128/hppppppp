# 文字型信息图：视觉编码

## 1. 核心视觉变量
- 字号：建立标题、分节标题、正文和注释的层级；
- 字重：强调关键词、结论和数字；
- 字体：匹配内容气质，同时保障识读；
- 行距/字距：控制阅读节奏和文字密度；
- 文本宽度：控制每行长度，避免过宽或过窄；
- 色彩：区分模块、强调信息或标记状态；
- 对齐：建立稳定的阅读边界；
- 留白：分隔模块、形成停顿和节奏；
- 图标/线条/色块：辅助分组和指引，不应喧宾夺主。

## 2. 视觉层级
通常建立标题、导语、分节标题、正文、重点信息、注释和来源等层级。层级差异应稳定，不宜每段文字都使用不同样式。

## 3. 常见问题
字号过小、行长过长、段落过密、重点过多导致失焦；字体风格过度装饰；色彩对比不足；标题和正文层级不清；文字与背景对比不够。

## 4. 可访问性
确保正文有足够字号和对比度；不要只用颜色区分文本类别；避免大段全大写或过度压缩字距；在数字和图表中保留清晰标签。
