# 文字型信息图：数据结构

## 1. 内容单元模型
将画面拆分为可管理的文本单元：
- block_id：文本模块标识；
- block_type：标题、导语、段落、列表、引文、数字、注释、来源等；
- content：文本内容；
- hierarchy_level：信息层级；
- sequence：阅读顺序；
- emphasis：强调级别；
- source_id：证据来源；
- related_block：关联模块。

## 2. 内容关系
- 标题—正文：概括与展开；
- 论点—证据：主张与支撑；
- 总结—细节：结论与解释；
- 列表—条目：并列关系；
- 引文—出处：引用与来源；
- 注释—正文：补充说明。

## 3. 文本预处理
核对事实、数字、专有名词、标点、断句和引用；删除重复表达；保留必要限定条件；不得为了视觉简化而改变原意。

## 4. 推荐数据表
建议维护一份内容清单，包含模块编号、原文、精简稿、层级、字数、来源、视觉强调方式和审核状态。这样便于排版调整后进行内容校对。
