# 文字型/列表型信息图形（Informational / List Infographics）类型分析

> 依据：《第三讲-信息图形类型学》PPT第23页。以下为基于课件标题与可见示例形成的工作定义；部分类型边界仍需更多案例验证。

## 1. 类型定义
以文字条目、人物/对象介绍、说明段落和列表结构为主要信息载体，通过编辑层级和版面组织实现快速浏览。

## 2. 基本数据逻辑
记录集合、文本模块、条目属性和排序/分组规则；重点在信息完整性、条目一致性和可扫描性。

## 3. 常见图形模型
信息卡片、清单、目录、分栏列表、带图注的条目、人物/对象资料板。

## 4. 视觉编码
标题字号、字重、分栏、项目符号、图标和留白建立阅读层级；图片作为条目识别辅助。

## 5. 信息架构
主题标题 → 分类/分组 → 条目 → 条目说明 → 来源。

## 6. 视觉叙事
从总体主题进入各条目，读者可按顺序浏览，也可按兴趣跳读。

## 7. 适用边界与风险
条目过密会使文字难读；若无统一分类和字段，容易退化为拼贴。
