# 词云图：视觉编码

## 1. 核心编码
- 字号/面积：通常映射词频或权重，是最主要的视觉变量；
- 位置：多由排布算法决定，除非明确设计空间分组，否则不代表坐标或关系；
- 色彩：可用于装饰、分类或情感/主题编码；若承担数据意义必须提供图例；
- 字体与字重：强化主次，但需避免让字体风格取代数据权重；
- 方向：横排、竖排或旋转可增加构图变化，但过多方向会降低阅读效率；
- 形状：轮廓词云可形成主题外形，但外形本身不应误导为真实地理或对象形态。

## 2. 设计规范
- 采用可读字体，控制最小字号；
- 大小映射应单调，避免权重较低的词异常突出；
- 限制色彩数量，确保对比度和色觉可辨识性；
- 关键词之间保留足够空隙，避免误读为固定短语；
- 重要词项可加注释或精确频次；
- 对不同语言分别检查字形、换行和字宽。

## 3. 常见问题
- 字号差异过大，低频词不可读；
- 词语碰撞或重叠；
- 颜色随机却被读者理解为分类；
- 轮廓限制造成词语权重与面积关系失真；
- 视觉排布造成虚假的语义聚类。

## 4. 可访问性
不要只依赖颜色表达类别；为关键词提供文本列表或数据表；图片应有替代文本，说明语料范围和大小编码含义。
