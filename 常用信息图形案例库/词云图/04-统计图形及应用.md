# 词云图：统计图形及应用

## 1. 主要统计依据
- 原始词频：词项在语料中出现的总次数；
- 相对频率：词频除以语料总词数，便于不同长度语料比较；
- 文档频率：包含该词项的文档数量；
- TF-IDF：衡量词项在某篇文档或某组文本中的区分度；
- 分组词频：比较不同时间、来源或群体的词项变化。

必须标注最终视觉权重究竟来自哪一种指标，不能将“字号更大”笼统解释为“更重要”。

## 2. 统计图形的角色
词云属于文本频率的视觉摘要，不是精确坐标统计图。若需要严谨比较，建议配套：
- 排序条形图：展示 Top N 词项及精确数值；
- 词频分布图：查看长尾分布；
- 分组小多图：比较不同语料组；
- 共现网络：在有共现窗口和边权定义时展示词项共现；
- 时间折线图：追踪词项频率随时间变化。

## 3. 常用计算
相对频率 = 词项出现次数 / 语料总词数。  
文档频率 = 包含该词项的文档数量。  
TF-IDF 的具体公式依所用实现而定，应记录平滑项、归一化方式和语料范围。

## 4. 使用边界
- 不应用词云比较大小接近词项的精确差异；
- 不应从高频直接推断赞同、反对或情绪；
- 不应将空间相邻误读为语义相关；
- 若需表达情感、主题或共现，应提供单独标注/建模依据。

## 5. 案例分析时记录
统计口径、词项筛选阈值、权重公式、Top N 数量、分组方法、是否提供精确数值表。
