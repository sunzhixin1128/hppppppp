# 词云图：数据结构

## 1. 原始语料层
建议保存文档级数据，而非只保留最终词频表：
- document_id：文档唯一编号；
- text：原始文本；
- source：来源；
- author / publisher：作者或发布机构；
- published_at：发布时间；
- language：语言；
- corpus_group：语料分组；
- sampling_method：采样方式。

## 2. 词项层
分词与清洗后形成词项记录：
- token：词或短语；
- normalized_token：归一化词项；
- document_frequency：包含该词项的文档数；
- term_frequency：词项出现次数；
- relative_frequency：相对频率；
- weight：最终映射到视觉大小的权重；
- category：可选主题类别；
- sentiment：仅在有可靠标注方法时使用。

## 3. 数据处理流程
原始文本 → 编码统一 → 分词/短语识别 → 去噪与停用词处理 → 同义词归并 → 词频统计 → 权重计算 → 过滤阈值 → 视觉排布。

中文需要说明分词工具和词典；英文需要说明大小写、词形还原和词干处理。专名、否定词和多词短语不应被机械删除。

## 4. 数据质量检查
- 样本是否重复；
- 语料来源是否偏向某一平台或群体；
- 停用词表是否误删关键概念；
- 同义词归并是否有依据；
- 词频是否受文本长度差异影响；
- 词项权重是否可复算。

## 5. 推荐输出
至少保存原始语料清单、清洗规则、词项统计表和最终绘图数据。只保留词云图片会使分析无法复现。
