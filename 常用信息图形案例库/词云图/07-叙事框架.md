# 词云图：叙事框架

## 1. 叙事目标
词云通常承担“快速建立主题印象”的角色，而不是独立完成完整论证。它通过高权重词项引导读者注意语料中的主要词汇线索。

## 2. 推荐阅读路径
研究问题 → 语料范围 → 视觉上最突出的词项 → 次级词项 → 词项之间需要验证的关系 → 方法说明与限制。

## 3. 叙事策略
- 主题概览：先呈现总体词项，再解释核心词；
- 分组对照：分别展示不同群体、时间或来源的词云，并配套精确统计；
- 变化叙事：比较不同时间窗口的词项变化；
- 主题发现：将词云作为探索入口，再通过主题模型、人工编码或共现分析验证。

## 4. 避免的叙事误区
- 高频不等于重要，更不等于观点认同；
- 视觉相邻不等于语义相关；
- 单一语料不能代表整个群体；
- 词云无法单独证明因果关系。

## 5. 结论表达
结论应限定为“在本语料及当前处理规则下，哪些词项出现较多/权重较高”，并指出需要进一步验证的语义关系。
