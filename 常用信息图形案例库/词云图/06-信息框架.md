# 词云图：信息框架

## 1. 基础结构
1. 标题：说明分析对象和核心问题；
2. 语料说明：来源、时间范围、样本数量和语言；
3. 主体词云：展示词项及权重；
4. 图例/方法说明：解释字号、颜色和筛选规则；
5. 重点词注释：解释关键概念、短语或异常词；
6. 数据来源与限制：说明语料代表性及处理方式。

## 2. 信息层级
- 一级：研究主题与语料边界；
- 二级：高权重词项；
- 三级：次级词项与可能的主题线索；
- 四级：方法、来源、口径和限制。

## 3. 组合方式
词云适合作为视觉入口，与 Top N 排序条形图、主题说明或分组对比图配合。不要把所有解释文字塞入词云主体。

## 4. 审核清单
读者能否知道词语来自哪里？大小代表什么？颜色是否有含义？词项是否经过清洗？哪些词项被排除？图形是否支持其声称的结论？
