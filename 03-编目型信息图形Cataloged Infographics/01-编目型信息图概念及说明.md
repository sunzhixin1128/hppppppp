# 编目型信息图概念及说明

> 文档性质：本类型的概念总文档；随案例持续更新。  
> 英文名称：Cataloged Infographics

## 1. 概念定义
编目型信息图形以**对象集合及其分类、索引、属性和可检索性**为组织核心。它把多个相对独立的对象按照共同规则编排，使读者能够浏览、查找、识别、筛选或比较对象。

其关键不是必须存在某一种统计图，而是将“有哪些对象、如何分类、每个对象有什么属性、对象之间如何比较”组织成可读的目录系统。对象可以是产品、物种、工具、人物、地点、概念或数据记录。

## A. 基本的数据逻辑
### A1. 核心数据结构
常见为记录集合（Record Set）或多属性表：
- id：对象唯一标识；
- name / title：对象名称；
- category：分类；
- attributes：对象属性集合；
- value：可比较的数值字段；
- tags：标签；
- image / icon：图像或符号引用；
- sort_key：排序依据；
- source：来源。

### A2. 关键关系
- 集合关系：所有条目属于一个研究范围；
- 分类关系：对象按一个或多个维度分组；
- 属性关系：每个对象由若干字段描述；
- 比较关系：对象在共同指标上可比较；
- 索引关系：对象可以通过名称、编号、标签或属性定位；
- 多维交叉：对象可能同时属于多个标签或类别。

### A3. 识别标准
如果对象条目本身是信息主体，分类、排序、网格或索引是主要组织方式，则具有编目型特征。若主要逻辑是父子包含，应优先判断为层级型；若主要逻辑是时间或地理位置，则分别判断为编年型或地理型。一个案例可以具有复合类型。

## B. 使用的统计图形与计算方式
常见形式：
- 分类目录、信息卡片网格、图标阵列；
- 表格、矩阵、比较表；
- 小 multiples（小多图）；
- 点图、条形图、排序条形图；
- 象形图、单位图、点阵图；
- 分类矩阵、筛选式目录和索引版式。

常用计算：
- 分类计数与频数分布；
- 类别占比：类别数量除以总数量；
- 属性分布、均值、中位数、范围和标准差；
- 排名、差值、比例与多指标标准化；
- 交叉表和类别组合计数；
- 缺失率、重复记录率和覆盖率。

统计图形应服务于条目比较。若各条目的量纲不同，不应直接使用同一长度或面积比例；必要时分指标展示或标准化，并说明标准化方法。

## C. 视觉编码
- **位置**：网格、行列、分组或排序位置用于组织条目；若位置没有数值意义，应避免造成量化误读。
- **重复单元**：统一卡片、图标或符号建立目录节奏。
- **形状/符号**：区分对象类型、属性或状态，需配合图例。
- **尺寸**：可表达数量、等级或重要性，但必须有明确数据依据。
- **色彩**：区分类别或状态；颜色含义保持一致。
- **文字**：名称、关键属性、简短说明和编号形成条目识别系统。
- **分组与留白**：明确类别边界，支持快速扫描和检索。

## D. 数据/信息架构
建议采用“总览 → 分类/筛选维度 → 条目集合 → 单条目属性 → 来源/补充说明”。
- 先定义收录范围和纳入/排除标准；
- 明确分类是否互斥、是否允许多标签；
- 统一每个条目的字段和展示顺序；
- 说明排序规则（字母、数值、重要性、使用场景等）；
- 对跨类别条目提供索引或标签；
- 对大量条目设置分页、分组或多级筛选。

## E. 视觉叙事架构
常见路径：
1. 总览式浏览：先理解对象集合；
2. 分类式浏览：按类别逐组查看；
3. 属性式比较：在共同指标下横向比较；
4. 索引式查找：通过名称、编号或标签定位；
5. 从代表性条目进入细节，再回到整体。

编目型信息图的叙事通常偏向“发现、识别、比较和查找”，不必强行设置戏剧化的起承转合。信息完整性、分类清晰度和检索效率往往比单一故事线更重要。

## 适用场景与局限
适用：产品选型、物种图鉴、工具清单、人物/概念介绍、材料目录、菜单、装备百科、数据集概览。

局限：分类标准含混、条目数量过多、属性字段不统一或比较维度不公平时，目录会退化为装饰性拼贴。需要建立数据字典和纳入标准。

### 案例驱动的修订
1. 编目型的关键不是“图中有很多条目”，而是对象集合、统一属性字段、分类口径和索引规则。
2. 编目型可叠加时间、空间或关系流：只要对象条目仍是主要信息单元，就可标注复合型。
3. 当图形重点变成父子分支，应优先判断为层级型；当重点是部件结构与标注，应优先判断为解剖型。
4. 案例分析必须说明条目范围、纳入标准、属性字段、分类是否互斥、排序规则和交叉索引。

### 分类核验提示
PPT第10—13页位于“编目型”章节，但其中至少包含明显的层级型、解剖型和编年型复合案例。仓库保留PPT原始章节归属，同时在案例报告中记录视觉逻辑判断，避免把课件页序直接当成严格的类型学证据。
